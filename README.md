# unlimited-auto-flow
UNLIMITED AUTO FLOW is a Manifest V3 Google Chrome extension designed to automate and streamline batch workflows on Google Flow (flow.google.com). It allows creators and power users to queue up to 1,000 prompts via text files or direct input, manage concurrent image and video generation pipelines (including Veo 3.1 and Nano Banana models), chain prompt references with @name and #name tags, automatically download generated media in organized directories, and remove watermarks in real-time using lossless canvas reverse-blending.
