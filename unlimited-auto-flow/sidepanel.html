    Fix unusual activity

    🧹Google shows an "unusual activity" block when you generate a lot in a row. It flags your Flow session on Google's side — not the extension. Clearing Flow's on-device site data resets it. You stay signed in to Google.

    Do this on the Flow tab
    1. Click the site info icon (⚙/sliders) at the left of the address bar, just before flow.google.com.
    2. Click Cookies and site data.
    3. Click Manage on-device site data.
    4. In On-device site data, click the 🗑 trash icon next to every entry — flow.google.com, google.com, www.google.com, accounts.google.com — deleting them one by one.
    5. Click Done.
    6. A reload button appears at the left of the address bar — click it.
    7. Back here, press Start to resume the remaining jobs.

    If it still persists right after, wait a few minutes and try again — or generate fewer in a row. Only Google can fully clear it.

    Download naming blocked

    🏷️Another extension is overriding download filenames, so your files would save with random names instead of the names you set (like 001_v1). The run was stopped and the misnamed file removed so you never keep a wrongly-named file.

    How to fix
    1. Click Open Manage Extensions below.
    2. Turn Off (or remove) any other downloader / auto-rename extension.
    3. Click the reload ↻ icon on UNLIMITED AUTO FLOW so it takes over naming again.
    4. Come back and press Start — your files will save with the correct names.
